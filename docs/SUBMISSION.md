# Hackathon submission checklist

## Confirmed guide requirements

- [ ] Project work began within the official hacking period.
- [ ] Source code is available in a public repository.
- [ ] A competition track is selected in the Devpost submission.
- [ ] AI assistance is disclosed accurately.
- [ ] The team can explain the high-level design and functionality.
- [ ] Devpost submission is complete by November 8, 2026, 11:00 a.m. America/New_York.
- [ ] The team attends the required judging expo, November 8, 11:30 a.m.–2:30 p.m. America/New_York.

These items are based on the supplied Hacker Guide. Incorporate any newer official organizer announcements when received. A separate Saturday 11:59 p.m. project form deadline has not been verified.

## Project delivery

- [ ] README states the problem, intended user, selected track, and scope.
- [ ] Setup and run instructions work from a clean checkout.
- [ ] Required environment variable names are documented without real credentials.
- [ ] Demo examples are labeled real/redacted/synthetic as appropriate.
- [ ] Evaluation describes the examples tested and the limits of the results.
- [ ] Evidence, uncertainty, and failure states are visible in the product.
- [ ] Public source, demo link, and any required media are included in Devpost.
- [ ] AI usage and third-party components are documented.
- [ ] The final demo has been rehearsed and a fallback recording is available if feasible.
